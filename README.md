# Minion-Style Software Engineering Agent

A production-oriented reference implementation of a **remote agentic software-engineering platform**.

The project is intentionally structured to teach the architecture behind long-running coding agents:

- natural-language engineering tasks
- persistent task/session state
- isolated execution environments
- agent runtime + context management
- repository/file/shell/git tools
- asynchronous orchestration and recovery
- bidirectional WebSocket event streaming
- repository/context/environment caching
- multi-repository task support
- GitHub pull-request publishing

The implementation is developed in six focused commits so each architectural layer can be studied independently.

> This repository is an educational reference implementation inspired by the distributed-system concepts behind production coding-agent platforms. It is not Uber source code and does not claim to reproduce proprietary internals.
